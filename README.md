# MonLauncher

Кастомный лаунчер и установщик для Minecraft NeoForge 1.21.1 (WPF / .NET 8 / C#).

## 🚀 Особенности
- **Автоматическая установка:** Распаковка базового клиента и зависимостей в %APPDATA%\.minecraft.
- **Тёмный интерфейс:** WPF с плавной анимацией, выбор темы оформления и новости.
- **Интеграция с CMLib.Core:** Надёжный запуск Minecraft, передача параметров памяти (RAM) и никнейма.
- **Автосохранение:** Никнейм и выделенная память сохраняются автоматически в launcher_config.json.
- **Однофайловая сборка:** Автономные .exe файлы без необходимости предварительно устанавливать .NET Runtime.

## 📁 Структура проекта
- src/ — Исходный код основного лаунчера (MonLauncher.exe)
- installer/ — Исходный код инсталлятора (MonSetup.exe)
- ds_setup/ — Конфигурации и скрипты для синхронизации модов и клиента на VDS
- publish_all.ps1 — Скрипт автоматической сборки single-file исполняемых файлов

## 🛠 Сборка
Для сборки требуется .NET 8.0 SDK:
`powershell
.\publish_all.ps1
`
Готовые исполняемые файлы создаются в корне проекта: MonLauncher.exe и MonSetup.exe.
